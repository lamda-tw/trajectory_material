# ZeroFail3、Random、Net3同状态机制实验

2026-10-20（北京时间）。**仅完成计划与已有文件静态核验；实验尚未开始。未来只用GPU1，不训练新模型。**

目的：解释ZeroFail3在旧1710步实验中的收益是否涉及三种行为——缺资料时有效获取信息、资料足够时采取有依据的行动、需要完整范围时正确补齐覆盖；再验证这些首步差异能否转化为后续官方检查改善。结果也可能否定这些解释。

策略为Random全池均匀抽样、Net3的P−F≥3、ZeroFail3的F=0且P≥3，均沿用旧1710步、1轮训练权重。使用三策略×三个seed的9个已有模型。在完全相同的历史消息、环境和输入token下替换下一步模型；状态同时来自三策略，防止只选择一组习惯访问的历史。

| 内容 | 设计 |
| --- | --- |
| 正式状态 | 129：57题覆盖参照+A/B/C各24；来源三组各43 |
| 独立校准 | 9状态；27首步动作及最多27次短续跑生成 |
| 正式下一步 | 129×9=1161个动作 |
| 动作评价 | 真实执行+公开证据盲评+官方逐检查；分别看行为收益与代价，不用P总分排名 |
| 后续验证 | 预选20状态：18核心+2旧发现复查；每种首步分别交给同样三种固定接手策略 |
| 后续上限 | 540分支，每分支12个额外模型步；在第4/12步或更早终态做evaluator |
| 预计量与时间 | 总模型生成≤7695，外部逻辑评分≤1416，正式evaluator≤2370；暂估7–15小时，校准后重估 |
| 启动限制 | 只用物理GPU1，先查空闲和锁；等待后续启动指令 |

与上一轮的关键区别：状态来自三策略；检验明确的“取资料→用资料→补范围”行为；预先纳入共同接手策略续跑，避免仅凭单步评分或即时数据库变化解释成功率。它仍不能单独识别哪条rubric或哪种训练样本造成收益，也不能把DEV上的探索当作新任务泛化证明。
