# Renderer specification — do not send this entire file to the model.

Common construction:
1. Restore the exact structured pre-action conversation and original system prompt.
2. C0: render it with the original chat template and generation marker; require its token ids to equal saved prompt_ids. Append nothing.
3. C1/C2/C3: append ONE user message below to that structured conversation, then apply the same chat template and generation marker. Do not concatenate after an already opened assistant generation marker. Do not put the original attempted action into an executed assistant-history slot.
4. All arms produce one replacement action under the original agent protocol. Execute only the normal parser's submitted code in a fresh copy of the PRE-ACTION state. The quoted diagnostic attempt never modifies that state.
5. Insert values as escaped data. Teacher inputs retain the original authorized local agent context. External feedback/judging payloads use equality-preserving credential redaction.

* C1 uses the same confirmed-rule list as C2/C3, not all unaudited historical F labels.
* C2 and C3 use byte-identical feedback_text and rule list.
* Full original answer appears only in C3. Small error quotations within C2 feedback are allowed and separately recorded.

* Record the rendered prompt, tokenizer/template hash, token count, arm, state id and independent sampling seed locally. Never expose arm/model metadata to the action judge.
