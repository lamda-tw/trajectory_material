## 成本与边界

- 20个逻辑候选，21次修复环境运行；多出的1次是上述基础设施重试。
- 教师进程调用21次，实际返回20个动作。
- 学生续跑132个动作，合计1,924,301个输入tokens、12,849个输出tokens。
- 教师只看替换动作之前的原始消息；不看原错误动作、后续轨迹、第2步诊断、官方失败条件或ground truth。
- 检查30题没有生成答案，原Qwen3-8B LoRA adapter未修改，GPU服务已停止。

- `freeze_summary.json`：最终类别数量与是否达到目标。
- `costs.json`：调用、环境、动作和token成本。
- `summary.json`：本步20题结果。

## 下一步决定

现在不能按原计划训练三组模型：恢复类只有1条，参数类只有7条，直接训练会把“样本量差异”混入能力组比较。下一步应先新增独立来源失败，重点收集报错后无效处理的恢复案例，并补至少1条参数成功；仍不从检查30题生成修复答案。只有状态、参数、恢复三类都达到预先规定的8条下界，才冻结匹配训练量和随机对照并进入短训。
