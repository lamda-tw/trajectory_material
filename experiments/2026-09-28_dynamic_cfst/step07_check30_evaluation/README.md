## 评测与基线复用

temperature=0、seed=100、32,000上下文、单次最多3,000输出tokens、最多50步、无reasoning parser、同一个simplified ReAct运行器和官方evaluator。State和Action分别占用独立GPU；Action先完成后，该卡运行Mixed。每个分支内部仍单进程、逐题从头运行。

原模型复用前已校验源adapter、提示词、agent实现和180个冻结证据文件；它在这30题上为17成功、13失败。所有新轨迹首条模型输入与同题基线逐字一致。新目录内train.txt只含冻结check30，历史train90及来源60题未改。

## 如何理解

三支都修好了一部分原模型的失败题，但同时损失了更多原本成功的题，因此本轮没有可接受的模型更新。Action与Mixed均为14/30，State为13/30；当前结果也没有显示专项训练在总成功数上超过Mixed。

上下文超限由原模型1题增至State 4题、Action 6题、Mixed 4题，模型调用总数也从588增至748、622、814。这些是后续诊断线索，尚不能据此把退步归因于某一个训练参数或能力类别。

先看新增成功和退步，训练loss不能替代任务结果。相同监督tokens仅控制目标答案曝光量，并不等于相同算力、步数或每样本重复次数。即使某专项分支更好，也只是本次设置下定向训练可能有价值的初步证据，不能单独证明分类正确。检查30题以前参加过原LoRA的SFT，不属于未见任务泛化评测。
