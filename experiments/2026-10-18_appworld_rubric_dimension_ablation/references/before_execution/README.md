## 本轮研究内容

在同样的训练步骤与更新预算下，分别完整删除八项 rubric 中的一项，观察训练样本、相同历史状态下的动作，以及 DEV57 任务成功如何变化。

原始来源是 Qwen3-8B 的 540 条轨迹、90 道训练题、11,254 个步骤；沿用已经核验的英文 v6 format 评分。此次不重新收集轨迹或调用评委。

## “完整删除 Ri”的准确含义

忽略 Ri 的全部标签，只检查其他七项：

```text
其余七项中的 P 数量 >= 3
其余七项中的 F 数量 == 0
```

其余七项允许 N/U；被删除的 Ri 是 P/F/N/U 都不影响资格。例如 DropR1 不计算 R1 的 P，也不因 R1=F 排除样本。R1 判为执行失败的步骤仍可入选，只要其他七项符合条件；不会另加执行成功或语法门槛。

从各自完整候选池全局等概率、无放回抽取 **1,358 个不同步骤 ID**。没有任务配额、题目平衡、重新分配/补足、内容去重、长度筛选或最终成功筛选；保留原始完整目标 token。内容相同但步骤 ID 不同的样本不因此被排除。

## DropR5 与 DropR7 为什么复用

本次实际评分表满足 `DropR5 候选 ID 集合 = DropR7 候选 ID 集合`，且都等于完整八项规则的 1,710 步集合。不是仅仅候选数量相等。

每个 seed 从原始基座新建 LoRA，训练一次 DropR5。DropR7 使用同 seed DropR5 的完全相同选样、顺序、初始化、模型与评测，记录 `alias_of=drop_r5` 和产物哈希；不另随机抽一份子集。它是同一训练条件的两个名称，不是两个独立重复。

**不是复用旧 ZeroFail3 模型。** 旧模型训练了 1,710 步，本轮训练 1,358 步；需要新训练 DropR5。也没有重新加入 ZeroFail3 训练项目。

因此是 **8 个报告组 × 2 seed = 16 个条件记录，7 种实际配方 × 2 seed = 14 次训练**，共 9,506 次更新、14 次 DEV57（798 个任务 rollout）。集合等价只成立于当前评分数据与阈值；后续数据变化要重新核验，不能据此说 R5/R7 普遍无用。
