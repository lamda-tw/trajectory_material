# 来源评分调试结果

时间：2026-10-21（Asia/Shanghai）。8 条独立调试轨迹各用原 v7 和 v7-feedback 评分一次，16 个逻辑请求均首次返回结构合法结果，无重新生成或格式修复。

| 检查 | 结果 |
|---|---:|
| 每个版本实际评分步骤 | 281 |
| 相同的逐维标签 | 2,225 / 2,248，98.98% |
| 八维标签串完全一致的步骤 | 264 / 281，93.95% |
| 选中目标 step 的八维标签完全一致 | 8 / 8 |
| 目标反馈结构可用且不超过 256 tokens | 8 / 8 |
| 目标反馈长度 | 62–88 Qwen tokens |
| 引用目标步之后观察的目标反馈 | 1 / 8 |

已对照目标代码、即时错误、相关前序事件和文档查询记录进行助手逐例证据复核。反馈覆盖重复使用不存在字段/接口、无效重复取凭据、未完成认证、重复查已有目录及未查完整 API 规格等问题，没有给完整替代答案。一个最早发行歌曲案例正确标记使用后续 schema 证据。

该歌曲案例的 R2 局部/全局覆盖边界仍有解释空间：原 v6 为 N，两种 v7 均为 F。具体 `created_at` 字段错误有直接证据；覆盖三种库的建议符合任务要求，但不能把此例当作 R2 标签完全正确的证明。原始结果均保留，没有为一致性改标签。

非目标步骤有 23 个维度、17 个步骤存在差异。本试验每个版本只有一次评分，不能区分评分随机性与新增输出说明的影响，也不能把 98.98% 当作准确率。复核来自当前 Codex 助手，不是独立人工金标。

结论：可以继续已授权的正式来源轨迹评分与 CPU 反馈整理。**这尚未验证 Qwen 纠错、任务推进或 SDPO 学习效果。** GPU、候选执行和训练门槛仍关闭。
