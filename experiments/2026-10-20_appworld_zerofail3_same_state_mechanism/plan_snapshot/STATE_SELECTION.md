# 冻结状态清单与取法

本文件只索引已经存在的轨迹，没有生成、重放或评分。总设计见 [PLAN.md](PLAN.md)。所有状态为**原轨迹第k步行动之前**；恢复前k−1步，不读取原第k步及以后作为决策材料。

## 1. 来源与复现

来源是旧1710步实验的Random、Net3、ZeroFail3，各三个训练seed、57个DEV任务，共513条轨迹。已有14258个状态出现记录、13796种完整前缀。九个权重与轨迹文件均已核对保存记录的SHA256。[source_manifest.json](source_manifest.json)记录来源；[models.json](models.json)记录权重。

[states_selected.csv](states_selected.csv)含精确来源路径、替换步号、完整前缀SHA256、重建消息SHA256、原prompt_ids SHA256及token数。研究者ID含来源和seed，不能交给评委；对外只用`public_state_id=state_<前缀哈希前20位>`。同一完整前缀只入选一次；跨来源出处另存[selected_prefix_provenance.json](selected_prefix_provenance.json)。

采样盐为`20261020:zerofail_same_state_v1`，排序值为`SHA256(盐 + ':' + 域 + '|' + state_id)`。静态复现脚本为[prepare_plan_index.py](prepare_plan_index.py)，仅用标准库读取已有文件，绝不执行轨迹代码。

## 2. 如何建立候选池

特征只来自公开任务、初始提示词及原前k−1步的实际代码、反馈和history_assistant_text。用AST读取`apis.<app>.<method>`及常量参数；只解析JSON，不执行Python。初始提示词中公开给出的真实规格可计已知；示例变量不能计为会话中已存在的变量。

完整规格的机械定义：同一个JSON对象具备`app_name/api_name/parameters/response_schemas`，且parameters为列表；仅从初始提示词与此前非异常输出收集。

| 面板 | 机械候选条件；语义是否适用仍待盲卡确认 |
| --- | --- |
| A | 紧前一步首次执行该段`show_api_descriptions`代码且成功；或一个未见完整规格的非文档API刚发生接口/认证/参数类错误（No API named、401、422、TypeError、unexpected keyword、missing argument）。“首次”指相同代码尚未出现，不保证相关文档此前没有用别的写法读过。 |
| B | 紧前一步成功输出完整规格。初始示例已知的重复规格仍可进入；评委应识别资料早已存在。 |
| C | 任务包含all/every/each/total/most/maximum/longest/highest/largest/sum/how many等范围线索，紧前一步成功，且符合下面任一子型。 |
| C：规格已取得 | 紧前一步输出完整规格，其参数有page_index/page_token/cursor。 |
| C：已见非空单页 | 紧前一步调用已知分页规格的非文档API，代码无for/while，输出中有非空JSON列表。它只是机械候选，可能是已完整的结果或与任务范围无关。 |

重叠候选归类优先级C > B > A；全部原始标记也保留。不是看到成功答案、ZeroFail3优势、旧评分或某模型当前动作后再选。**d4e9306另设的两个续跑桥接状态是明确的例外：家族来自既有收益发现，必须标为发现复查、单独报告。**

## 3. 抽样与配额

1. 57个题目参照：家族按`SHA256(盐+':family|'+family)`排序，家族内三个任务按ID排序。家族序号i、题目序号j决定来源组`[random,net3,zerofail3][(i+j)%3]`、来源seed`[15,16,17][(i+2j)%3]`；在该条轨迹中按域anchor哈希取1个状态。每来源19状态、每来源seed19状态。
2. A/B/C各24状态：8轮×三来源，排除此前已选完整前缀。依次优先“本面板此前该任务入选数少、该家族入选数少、该来源中该seed入选数少”，再按域focus_A/B/C哈希。它是多样性优先，不是按质量排序，也没有失败率/语法过滤。C每轮交替两个子型，每来源各4+4。
3. 校准9状态：每面板×来源1个，按calibration_A/B/C哈希取；排除全部正式前缀。C的Random/ZeroFail3取单页子型，Net3取规格子型。校准结果不并入正式。
4. 核心续跑18状态：仅从已冻定向面板取，每面板×来源2个，before_step≤38，以给首步后留下12步；优先未覆盖题目/家族，再按continuation哈希。C每格两子型各1。
5. 发现桥接2状态：仅从已冻结C面板的d4e9306家族取Net3来源和ZeroFail3来源各1个，before_step≤38，排除核心续跑，再按discovery_bridge哈希。这两个不并入核心18的总体结果；没有强行补Random来源。

正式129状态覆盖57题19家族，来源各43；来源seed15/16/17分别42/42/45。A、B均各24题19家族，C为24题13家族。被测模型seed始终各3个，与来源seed配额无关。

机制候选的语义误判、卡片uncertain或重放不一致均不得换样。三个面板分别在共同yes状态上比较；不足预定覆盖门槛时只能报告探索性描述。未知、不适用和所有失败也公开列出。

## 7. 冻结后允许和禁止的变更

允许修复基础设施并以相同输入断点恢复，必须记版本与影响范围。若来源文件、提示词、选样算法、配额或状态清单改变，必须升版本重新冻结并明确尚未查看哪些结果；不能把修复当成静默重选理由。正式129个状态的模型动作在校准和全部前缀卡片冻结前不得生成。
